How to Install Django AiWave Templates

1. Download and Extract the Zip File:

Download the zip file containing all files integrated with AiWave. Extract the contents of the zip file to your desired location.

2. Install Python and Django:

Make sure Python (We recommend version 3.12.3) and Django (We recommend version 5.0) are installed on your machine. If not already installed, you can download and install Python from the official website. To install Django, you can use pip: pip install django==5.0

3. Install Required Packages

Open your command prompt or terminal, navigate to the directory where you extracted the AiWave project, and run npm install to install Node modules. Install Required Packages Type: pip install -r requirements.txt

4. Generate CSS using SASS compiler:

To generate CSS from SCSS, execute the command: npm run build If you want to run compiler in watch mode run: npm run dev

5. Initialize Django Database:

To initialize Database execute the command: python manage.py makemigrations && python manage.py migrate

6. Run the Project

to run the project execute the command: python manage.py runserver

7. Editing AiWave Template

Before all that you have to edit your template and place your own contents by replacing old demo contents, in this case, you will need a code editor such as – VScode, Sublime Text etc.

Changing Images

To change any images of the website

  1. Carefully collect the source name of the image (i.e. banner-img.jpg)
  2. Open the file called images.
  3. Find the particular image file.
  4. Replace the file with your image.
  5. Make sure that the file name does not change.The file name should be the same.

Example: Suppose you want to change the following image file:

                                                    
                                                        <div class="logo">
                                                            <a href="index.html">
                                                                <img class="logo-light" src="assets/images/logo/logo.png" alt="ChatBot Logo">
                                                            </a>
                                                        </div>

You have to do the following to change this image with your own image:

  1. Open the file called images.
  2. Find the particular image file called banner-img.jpg
  3. Replace the file with your image
  4. Make sure that the file name does not change.
Note

Images seen in the live preview are only set for preview purposes. They are not included in the download files.

User Guide


Welcome to AiWave User Guide You can see how to navigate throughout website from this section

Landing Page & Navigation

When you first visit the Wowdash website, you’ll land on the Home Page. Here’s what you’ll find:

Header (Top Bar)
  • Logo: Clicking the logo always brings you back to the home page.
  • Main Menu: At the top (or in the mobile menu), you’ll see links to the main sections of the site, such as Tools, Blog, Pricing, Help, and more.
  • Login/Logout Button: If you’re not signed in, you’ll see a “Login” button. If you’re already signed in, you’ll see a “Logout” button.


Main Banner
  • A welcoming message introducing Wowdash’s AI features.
  • A prompt box where you can try out AI features right away (for example, generating text).
Quick Access Buttons
  • “Start with AI” or “Get Started Free” buttons take you directly to the main AI tool.
Footer (Bottom of the Page)
  • Additional links to privacy policy, terms, contact, and social media.
How to Navigate
  • To Explore Tools: Use the main menu to find and click on “Tools.” This will show you all available AI generators (text, code, blog, etc.).
  • To Read or Write Blogs: Click on “Blog” in the menu to read articles or, if you’re signed in, create your own.
  • To Get Help or Support: Click on “Help” or “Contact” for FAQs, support, and ways to reach out.
  • To View Pricing or Plans: Click on “Pricing” to see available plans and features.
  • To Sign Up or Log In: Use the “Login” button in the header. If you don’t have an account, you’ll be able to sign up from the login page.


Authentication




How to Sign Up (Create an Account)
  • Go to the Login Page:
    Click the “Login” button in the top right corner of the home page.
  • Choose “Sign Up”:
    On the login page, look for a link or button that says “Sign Up” or “Create an Account” (usually below the login form).
  • Fill Out the Registration Form:
    Enter your details (such as name, email, and password). Some sites may ask you to confirm your email address by clicking a link sent to your inbox.
  • Submit:
    Click the “Sign Up” or “Register” button. You may be automatically logged in, or you might need to log in after confirming your email.
How to Log In
  • Click “Login”:
    Use the “Login” button in the header.
  • Enter Your Credentials:
    Type in your email and password.
  • Submit:
    Click the “Login” button. If your details are correct, you’ll be taken to your dashboard or the main page.
How to Log Out
  • Find the Logout Button:
    Once logged in, the “Login” button in the header changes to “Logout”.
  • Click “Logout”:
    Simply click the “Logout” button to securely sign out of your account.
Troubleshooting
  • Forgot Password?
    On the login page, click “Forgot Password?” and follow the instructions to reset your password via email.
  • Didn’t Receive Confirmation Email?
    Check your spam/junk folder, or click “Resend Confirmation” if available.

Account Settings
  • Settings Section:


    Navigate to the Environment Settings section in the admin panel. Select the relevant tab (General, Facebook, Gemini, etc.). Enter or update the required keys and settings in the provided fields. Click Save to apply your changes. All updates are securely stored and take effect immediately.

    1. General Settings

    This page allows you to configure all the necessary email-related environment variables for your website. These settings control how your website sends emails (such as password resets, notifications, and alerts).

    • Default From Email: The email address that will appear as the sender for all outgoing emails from your website.
      Example: noreply@yourdomain.com
    • Email Backend: The backend service or library used to send emails. For most Django projects, this is typically set to django.core.mail.backends.smtp.EmailBackend.
    • Email Host: The SMTP server address used to send emails.
      Example: smtp.gmail.com for Gmail.
    • Email Host User: The username (usually an email address) used to authenticate with the SMTP server.
    • Email Host Password: The password or app-specific password for the email account used to send emails(make sure to use app password instead of actual password).
    • Email Port: The port number used by the SMTP server.
      Example: 587 for TLS, 465 for SSL.
    • Email Use TLS: Indicates whether to use TLS (Transport Layer Security) when connecting to the SMTP server.
      Example: True or False.
    • Usage: These settings must be filled out correctly for your website to send emails. If any value is incorrect, email delivery may fail.

    2. Facebook Key Settings

    This page is for configuring the credentials required to integrate your website with Facebook’s API. These are necessary for features like Facebook login, sharing, or any other Facebook-related functionality.

    • Facebook App Id: The unique identifier for your Facebook application. You obtain this from the Facebook Developer Console.
    • Facebook App Secret: A secret key associated with your Facebook application, also found in the Facebook Developer Console. This should be kept confidential.
    • Usage: Enter the App ID and App Secret exactly as provided by Facebook. These credentials allow your website to securely communicate with Facebook’s services.

    3. Gemini Key Settings

    This page is for managing the API key required to use the Gemini API (for example, for AI, chat, or other integrations provided by Gemini).

    • Gemini API Key:The secret key provided by Gemini for accessing their API. This key authenticates your website’s requests to Gemini’s services.
    • Usage: Paste your Gemini API key here to enable features that depend on Gemini’s API. Keep this key secure and do not share it publicly

User Section

The User Section of the admin panel provides a comprehensive interface for managing all user accounts on your platform. Here, administrators can view, search, and filter users, as well as perform essential actions such as activating, deactivating, or deleting accounts. The user list displays key information including name, email, department, designation, status, and registration date, all in a clear and organized table.



Key Features Include:
  • Add User: Ability to add users.
  • User Listing: View all registered users with essential details at a glance.
  • Search & Filter: Quickly find users by name, email, status, or other criteria.
  • Status Management: Easily activate or deactivate user accounts with a single click.
  • Admin Filter: Instantly toggle between viewing all users or only admin users.
  • Bulk Actions: Select multiple users for batch operations (if enabled).
  • Responsive Design: The user table is optimized for all screen sizes, ensuring easy access and readability.

Release Note

The Release Notes section allows administrators to document and share important updates, new features, improvements, and bug fixes with all users of the platform. This section helps keep everyone informed about the evolution of the website and ensures transparency about changes.



View All Release Notes:

See a chronological list of all past releases, including version numbers, release dates, headings, and a summary of new features or changes.

Add a New Release Note:

Administrators can add a new release note by filling out a simple form with the following fields:

  • Version: The version number of the release (e.g., 1.2.0).
  • Release Date: The date when the release goes live.
  • Heading: A short title or summary for the release.
  • Features: A detailed list or description of new features, improvements, and bug fixes included in this release.
Delete a Release Note:

If a release note was added by mistake or is no longer relevant, administrators can delete it.

How to Use the Release Notes Section
  1. Access the Section: Go to the Release Notes page from the admin dashboard.
  2. Add a Release Note: Fill in the version, release date, heading, and features in the provided form. Click Save to add the new release note. It will appear in the list for all users to see.
  3. View Existing Notes: Browse the list to see all previous releases and their details. Users can read about what’s new or changed in each version.
  4. Delete a Release Note: If you need to remove a release note, use the delete option next to the relevant entry (admin only).
